# Blinkit Sales Analysis

Exploratory data analysis on Blinkit sales data (8,523 records) using Python, Pandas, and Matplotlib/Seaborn to uncover sales trends across item categories, outlet types, and locations.

# Key Findings
- Total Sales: $1,201,681.5 | Avg Sales: $141 | Avg Rating: 4.0/5
- Low Fat items drive 64.6% of total sales
- Fruits & Vegetables and Snack Foods are top-selling categories
- Tier 3 outlets and Medium-sized stores generate the highest sales

# Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
